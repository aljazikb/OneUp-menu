# Cafe Menu Website

This project is a digital menu website designed for a café.  
It allows customers to easily browse drinks and food items online using their phone.

## Features
- Simple and modern design
- Mobile-friendly layout
- Menu categories (Coffee, Drinks, Desserts)
- Images for menu items

## Technologies Used
- React
- Tailwind CSS
- HTML
- CSS
